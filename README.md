# Aishwarya Shanmugam — QA & Test Automation Portfolio Website

This repository contains the source code for my personal portfolio website, hosted 100% for free via **GitHub Pages**.

## Live URL
👉 **[https://aishwaryyaa12.github.io](https://aishwaryyaa12.github.io)**

## Features
- **Modern Responsive Design**: Built with Tailwind CSS, Lucide icons, and modern glassmorphism UI.
- **Zero Build Setup**: Pure HTML5 & CSS that loads instantly on any browser or mobile device.
- **Showcase Sections**:
  - Hero with career highlights and direct contact links
  - Key impact metrics from Bettermile (coverage 0% → 25%, -15% regression time)
  - Interactive GitHub portfolio project cards
  - Core skills & technical toolkit
  - Work history & education timeline
